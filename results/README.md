# Result artefacts

Write-ups (`*.md`) and the small JSON artefacts the paper's numbers are read from. Large artefacts
(activation memmaps, trained SAE weights, full feature catalogues) are **not** in git — they run to
hundreds of gigabytes. Regenerate them with `docs/04-reproduce.md`, or browse the released features
in the interactive atlas: https://biodyn-ai.github.io/c2s-atlas/

`docs/05-results.md` maps every claim in the paper to the file it comes from.
