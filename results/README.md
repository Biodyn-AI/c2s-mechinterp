# Result artefacts

The current paper uses the audited numerical release and the summaries in `results/revision/`.
[`docs/05-results.md`](../docs/05-results.md) maps its claims to source artefacts and defines the
relevant denominators and controls.

The pre-existing write-ups and JSON files directly in this directory are retained as historical
run records. Their annotation percentages, regulatory conclusions and partial-depth scaling
numbers are superseded by the controlled analysis. They should not be read as current findings.

Full feature catalogues, per-factor statistics, designs and source manifests are distributed as
versioned release assets to keep the Git repository small. Primary count matrices and large
activation intermediates are not redistributed; use the source accessions and commands in
[`docs/04-reproduce.md`](../docs/04-reproduce.md). Trained dictionaries and their measurements are
preserved with the experiment archive. Complete atlas feature details are also available at
https://biodyn-ai.github.io/c2s-atlas/.
